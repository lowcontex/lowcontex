### 🚀 Highlights & Featured Projects

**📋 [ePetCare — Veterinary Clinic Management System](https://github.com/lowcontex/epetcare)** *(Django · PostgreSQL · PySide6 · DRF)*
Capstone project — a full-stack veterinary clinic system with a Django web app **and** a PySide6 desktop client sharing one PostgreSQL database.
- **Architecture:** REST API (Django REST Framework) syncing data between web and desktop clients
- **Key Features:** Role-based portals for pet owners & vets, appointment/medical record management, OTP-based password reset, email notifications, deployed to Render with automated build pipeline

**🏗️ [construction-appointment-web](https://github.com/lowcontex/construction-appointment-web)** *(Next.js · TypeScript)*
Collaborative appointment scheduling web app for a construction business, built with a friend.

**🐕 [corgi-apps (CorgiNite)](https://github.com/lowcontex/corgi-apps)** *(Electron · React)*
Desktop utility app with a custom batch installer script using winget with a Chocolatey fallback.
